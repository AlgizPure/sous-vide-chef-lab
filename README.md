# Sous-Vide Chef Lab & Mobile Web PWA (v3.14 — Sticky Compact Header & Quick Navigation)

Профессиональное мобильное веб-приложение (Anti-Slop PWA) для приготовления блюд методом Sous-Vide, интерактивный каскадный планировщик для владельцев одного аппарата (Cascade Single-Unit Planner), калькулятор сухого посола (пресола), атлас разделки говядины (Butchery Guide), 104 профессиональные техкарты, изысканная фотогалерея с полноэкранным Lightbox-просмотром, компактный прилипающий хедер (Sticky Compact Header) с быстрым поиском и мгновенной навигацией, и категоризированный список покупок со специями от Шефа Демьяна.

---

## 📱 Функциональные модули

0. **Умный прилипающий компактный хедер (Sticky Compact Header & Quick Navigation):**
   - **Компактный режим при скролле вниз:** При прокрутке страницы вниз хедер плавно уменьшает высоту (с ~64px до ~44px), скрывает вспомогательный подзаголовок и включает матовое полупрозрачное стекло с размытием фона (`backdrop-filter: blur(18px)`), освобождая максимум полезного пространства для рецептов.
   - **Мгновенный доступ к навигатору рецептов:** Кнопка вызова меню-шторки с актуальным счетчиком (104 техкарты) всегда закреплена в левом верхнем углу — переход в любую категорию или к избранному возможен в 1 клик из любой глубины ленты.
   - **Быстрый поиск прямо из компактного хедера:** Кнопка поиска в шапке разворачивает компактную строку поиска с живой двухсторонней фильтрацией рецептов в реальном времени без необходимости скроллить обратно наверх.
   - **Возврат наверх в 1 тап:** Клик по названию «Sous-Vide Lab» запускает плавный кинематографичный скролл к началу страницы (`window.scrollTo`).

2. **Каскадный планировщик одного су-вида (Single Sous-Vide Cascade Planner):**
   - **Физика каскадного протокола (High-to-Low Temp):** Единственно верный способ готовить комплексный ужин или заготовки в одном су-виде — двигаться от высоких температур к низким (85°C ➔ 80°C ➔ 75°C ➔ 64°C ➔ 55°C).
   - **Быстрый сброс температуры (Rapid Temp Drop):** Снижение температуры ванны с 85°C до 55°C добавлением 1–2 ковшей холодной воды или льда занимает 1–2 минуты (в отличие от опасного многочасового нагрева с мясом внутри).
   - **Режим Holding (Теплый резерв):** Приготовленные при 85°C гарниры (спаржа, овощи) и десерты в баночках остаются в ванне при 55°C на все время варки стейка — они не перевариваются и подаются к столу идеально теплыми одновременно!
   - **Кнопка «⚡️ Оптимизировать каскад»:** Автоматическая сортировка очереди по убыванию температуры с динамическим расчетом дельты охлаждения ванны и подсказками по льду и воде.
   - **3 готовых шеф-каскада в 1 клик:**
     - *«Шеф-Ужин: Стейк + Спаржа + Десерт»* (85°C пирог Kerr ➔ 85°C спаржа ➔ Сброс ванны ➔ 56°C стейк стриплойн + обжарка 45 сек).
     - *«Воскресный бранч: Омлет + Onsen Egg»* (75°C омлет-ролл ➔ Сброс ➔ 64°C яйца Onsen Tamago).
     - *«Meal Prep: Конвейер заготовок на неделю»* (85°C овощи ➔ 74°C бёдра ➔ 61°C грудка ➔ шоковое ледяное охлаждение).
   - **Встроенный таймер активного этапа:** Визуальный прогресс-бар, цифровой отсчет времени, Web Notifications пуш-оповещения и звуковой сигнал завершения шага.
   - **Быстрые технологические таймеры:** Сухой посол (30 мин), шоковое охлаждение в воде (15 мин), финишный колер на сковороде (45 сек).

## 🚀 Деплой на Vercel

Проект полностью автономен и не требует сборщиков (Zero Build Step).

### Вариант 1: Через Vercel CLI
```bash
cd /home/algiz/projects/2b/sous-vide
vercel --prod
```

### Вариант 2: Через GitHub / Vercel Dashboard
1. Создать репозиторий на GitHub.
2. Подключить репозиторий в панели [Vercel](https://vercel.com).
3. Root Directory: `sous-vide` (или корень репозитория).
4. Нажать **Deploy**.
