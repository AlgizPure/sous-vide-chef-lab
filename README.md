# Sous-Vide Chef Lab & Mobile Web PWA

Профессиональное мобильное веб-приложение (Anti-Slop PWA) для приготовления блюд методом Sous-Vide, калькулятор сухого посола (пресола), умный мульти-таймер с Web-оповещениями и интерактивный список покупок со специями от Шефа Демьяна.

---

## 📱 Функциональные модули

1. **Кулинарная книга (Cookbook — 66 техкарт):**
   - **Интерактивный живой поиск:** Мгновенная фильтрация по названию блюда, мясному отрубу, специям или автору.
   - **Компактный аккордеон карточек:** Легкий просмотр десятков рецептов без визуальной перегрузки; пошаговые шаги и списки ингредиентов раскрываются по клику на «📖 Техкарта».
   - **Эксклюзивные техкарты от Шефа Демьяна:** Птица на кости 66.5°C, говяжья лопатка для спорта (2 режима), пред-колер в муке, Оссобуко с Мирпуа, Pepper Стейк, Зирвак для плова, Свиные ребра 2 текстур, официальный ресторанный рыбный протокол (треска, тунец Sashimi 42°C, судак, окунь).
   - **Мастер-классы шефов с YouTube:** Стриплойн Medium с вустерским соусом и зеленая спаржа (Олег Чешик, V-ZUG), наука сочности куриной грудки (Доброслав13), умные заготовки Meal Prep на 14 дней (Маша Шелушенко).
   - **Золотая коллекция форума «Хлебопечка.ру» (30+ рецептов из 2159 постов):** Домашняя ветчина в ветчиннице (Белобока/Tescoma), молочные сосиски и сардельки, шелковый говяжий язык, щечки в красном вине, утиный рийет длительного хранения, паштет из куриной печени в баночках Twist-off, карельская форель Anti-Albumin, кальмары без резины, пряная скумбрия, глазированная морковь с тимьяном, кукуруза в початках, ускоренное лимончелло за 2.5 часа, топленое карамельное молоко.
   - **Быстрые подкатегории 2-го уровня:** Фильтрация по типам приготовления (стейки, томление 8–48ч, на кости, ветчинница, сосиски и др.).
   - Конструктор собственных рецептов с авто-сохранением в `localStorage`.

2. **Калькулятор посола и маринада:**
   - Формула шефа: 10 г соли + 5 г сахара на 500 г сырья (2% соль / 1% сахар).
   - Режим плотного посола (20г / 10г на 1 кг).
   - Переключатель «Соленый соус» (авто-уменьшение соли на 50%).
   - Рекомендации по чесноку (удаление зеленого ростка).
   - Запуск таймера посола (30 минут) в 1 клик.

3. **Умный Мульти-Таймер (Smart Timer):**
   - Звуковой гармонический сигнал (Web Audio API без внешних аудиофайлов).
   - Вибрация на мобильных устройствах (`navigator.vibrate`).
   - Web Notifications API — пуш-уведомления на телефон о завершении каждого этапа.
   - Фоновая устойчивость по таймстампам (не сбивается при блокировке экрана).

4. **Список покупок (Shopping List):**
   - Облако рекомендованных специй от Демьяна (Тимьян, Розмарин, Сухой чеснок Metro, Свежий имбирь, Соус Ворчестер, Бальзамик, Хондаши, Дашида, Демиглас и др.).
   - Импорт ингредиентов из любого рецепта в 1 клик.
   - Умная группировка по категориям (Специи / Продукты).
   - Быстрый поиск ингредиентов на маркетплейсах (Ozon, WB, Яндекс.Маркет, Купер, ВкусВилл).

5. **Шеф-Гид с тематическими вкладками (Guide Tabs):**
   - **⭐️ Законы Шефа:** 5 технологических постулатов Демьяна, правила кости 66.5°C, миоглобин, соление.
   - **🧪 Наука и тесты:** Лабораторный эксперимент влагопотерь (Доброслав13: 40 мин при 65°C = 8.5% потерь vs 3 часа при 62°C = 17% потерь), влияние сливочного масла на сочность.
   - **🎥 Видео-мастера:** 4 YouTube-урока с таймкодами, прямыми ссылками и технологическими выводами.
   - **💡 Лайфхаки упаковки:** Энциклопедия форума «Хлебопечка.ру» (трюк с бумажной салфеткой для гладких пакетов, ложка/магнит против всплывания, правило «двух пальцев» Finger-Tight для баночек Twist-off, Anti-Albumin солевой барьер).
   - **🥓 Ветчинницы и колбасы:** Секреты экстракции миозина (белковые нити), температурный порог фарша до +10°C, баланс нитритной соли 50/50, режим 68°C 3.5–4.0ч.
   - **🛡 Сроки и HACCP:** Официальные протоколы дефростации, сроки хранения пастеризованной продукции в вакууме (+2...+4°C до 14 дней), маркеры анаэробной порчи.

## 🚀 Деплой на Vercel

Проект полностью автономен и не требует сборщиков (Zero Build Step).

### Вариант 1: Через Vercel CLI
```bash
cd /home/algiz/projects/2b/sous-vide
vercel --prod
```

### Вариант 2: Через GitHub / Vercel Dashboard
1. Создать репозиторий на GitHub.
2. Подключить репозиторий в панели [Vercel](https://vercel.com).
3. Root Directory: `sous-vide` (или корень репозитория).
4. Нажать **Deploy**.

## 📂 Структура файлов

- `index.html` — Одностраничное мобильное приложение.
- `app.js` — Логика состояния, база рецептов, таймеры, синтезатор звука, список покупок.
- `style.css` — Анти-слоп стили, темная палитра, адаптивная верстка.
- `sw.js` — Service Worker для оффлайн-работы.
- `manifest.json` — Манифест для установки PWA на Android/iOS.
- `vercel.json` — Конфигурация Vercel.
- `knowledge-base.md` — Структурированная каноническая база знаний.
